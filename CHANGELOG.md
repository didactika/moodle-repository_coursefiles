## [1.0.0-m400] - 2026-10-11

First release of the Moodle 4.0 to 5.2 line, on `MOODLE_400_STABLE`. The Moodle 5.3 line is on `main` (1.0.0-m503).

### Added

- The FileBank library inside the normal file picker of Moodle: files and complete folders of related courses can be selected with cards, list and lazy tree views and recursive multiple selection, reviewed, and imported into the activity.
- It needs `local_filebank`, installed from the same line.
- The interface is written in AMD modules and Mustache templates, with the same features as the 5.3 line.
